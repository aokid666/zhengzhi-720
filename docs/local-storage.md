# v122：本机大记录保存与同步状态

学习记录、笔记和手写从 localStorage 自动迁移至 IndexedDB（zz720-learning / records / snapshot）。令牌、外观和少量同步元数据继续留在原来的轻量存储中。

- 应用启动先等待数据库加载完成，再恢复学习队列和启用云端同步。
- 首次迁移只有在完整读写事务完成后才释放原 zz720.v1.data。写入失败时保留旧副本；旧标签页在事务期间改写的副本也会留下，直到下一次成功合并。
- 数据库读写事务读取最新快照并使用现有字段版本、删除标记和计数合并规则。BroadcastChannel 和轻量通知让其他页面刷新本机快照。
- 数据库错误与 GitHub 网络错误分别记录。云端上传成功后保留真实的本机保存错误，界面显示“云端已同步 · 本机保存异常”。
- 数据库不可用时保留旧存储回退。已迁移设备无法读取主数据库时停止上传，避免拿空记录覆盖备份；当前内存里有正常记录但写入失败时仍可上传云端救援。
- 同步诊断新增存储后端、估算数据量、本机写入状态与导出按钮；大于1MB的云端记录通过鉴权原文读取显示记录数。
- 原始存储损坏时保留原数据并停止上传。此更新不压缩或删除笔记、手写、历史及冲突版本，也不改动云端 userdata 数据结构。

验证：完整同步、题库与交互检查；使用 fake-indexeddb 的事务事件验证大记录迁移、离线重开、事务中断、跨标签页、删除、上传期间新修改及旧页面迁移竞态。部署后只核对网站代码，不操作用户真实 userdata 文件。
