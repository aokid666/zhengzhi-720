原始资料按 SHA-256 验证，在四个独立 GitHub 仓库内由 Actions 提取、识别、校对并发布。优先直接保存 PDF 内嵌图片的原始字节；矢量页或无法直接对应整页的图片首次渲染为 225 dpi PNG。后续网页只按坐标显示片段，不转格式、不重新压缩图片。

- `zz-history-notes-2027`：党的重要会议、毛著作总结、土地政策、史纲时间轴；只给史纲、毛中特相关题提供经原文核实的对应页。
- `zz-tuijie-exams-2027`：腿姐八套卷，试题册 65 页、解析册 114 页，按套与原题号配对；264 道选择题，保留批注式解析和原图。
- `zz-tuijie-manual-2027`：腿姐背诵手册下册 88 页，统一显示在“腿姐背诵手册”对照入口；本次上册未成功接收，明确标注待补充。
- `zz-tuijie-selftest-2027`：背练结合自测本，按原书 30 天拆出 149 道填空自测，并以手册对应原文与截图核对。填空采用本人自评，不制造自动评分。下册没有另行编排的练习题，其配套自测由此书提供。

“腿姐背诵手册”与“史纲专题资料”分别显示原图、对应文字、浏览整本、原 PDF。整本阅读支持独立全文搜索、上下连续滚动、页码跳转和工具栏收起。腿姐背诵手册也可从讲义分屏选择。

旧题的补充关联采用内容签名校验，只有题面、选项、答案、解析仍一致时才加载。已有题库、题目 ID、学习记录、个人同步分支均不替换。新题库沿用收藏、错题、记录、艾宾浩斯和测试模式（客观题）。
