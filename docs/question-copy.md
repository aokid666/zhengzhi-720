# 一键复制题目

每道题的题面上方提供“一键复制”。复制题干、全部选项、正确选项及其文字、解析，并保留题库与章节信息。可在作答前使用；复制本身不提交、不判分、不修改学习记录。

连线题复制左右项和配对答案；图片挖空题复制带空位编号的文字与各空答案；判断订正、填空等自评题明确说明需对照原文核对。已编辑的解析文字优先复制当前编辑内容。

优先使用浏览器剪贴板接口；受限时尝试传统复制，再提供可全选的文本框。不读取剪贴板，不自动向其他网站或 AI 服务发送内容。
