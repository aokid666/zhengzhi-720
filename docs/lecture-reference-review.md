# 讲义缺失关联复核

复核原题、专题练习、手册习题和辨析题、全部冲刺资料的缺失关联。知识清单、速成班讲义、背诵手册分别定位；不改动原题、现有页码、题目 ID 或 userdata。

旧规则需要至少六个连续 12 字片段，短考点及措辞变化容易漏配。新规则以正确选项、逐项连线配对、挖空答案及解析中的肯定性表述为查询单位，保留有限范围内的设问—答案证据，或有区分度的完整答案原句。不以相同主题或邻近章节代替证据。知识清单还校验学科范围；手册习题区不充当理论讲解页。

“主要形式/主要敌人”“社会历史条件/实践基础”“根本特性/本质属性”等关系必须分别验证。原文虽然同时含有“武装斗争”和“中国革命”，也不能因此把三大法宝清单作为主要形式的证明。回归样例固定检查手册 u080/u081 的正确说明并排除 l105 的误配。

对语义明确但措辞差异大、表格阅读顺序错乱、内容跨页的个别考点，保留人工复核记录 `scripts/lecture-reference-reviewed.json`。例如感性认识的“直接性、具体性”所在对照表、价值增殖的“一定点”与必要劳动的关系、宪法四项原则跨 PDF 第 95—96 页。构建检查题目提示和原文锚点，原文变化导致失效时停止导出。

每条补充关联含原文摘录，人工复核项另有定位提示。页面在原有截图前提供折叠的“本题考点对应原文”，分屏使用同一套补充页码。摘录使用现有文字数据，截图仍引用原资产，不进行图像转换。

生成输出采用独立覆盖层，仅补缺失字段。题干、答案、选项、解析、连线关系的内容签名不同则不应用，防止其他编辑改变题目后套用过期关联。客户端按正在学习的资料按需加载精简文件，不在首页下载全量复核报告。存储和同步数据结构保持不变。

GitHub Actions 生成完整复核报告和逐资料精简输出，检查原文摘录、学科、页码、来源、现有交互及正反例，提交到复核分支。检查后正常合并最新 main 发布，不强推。没有得到可靠证据的项目仍保留“暂未定位到可确认的对应讲解”，不据此断言讲义不存在该知识点。
