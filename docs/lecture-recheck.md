# 补查未定位的讲义对照

在 GitHub Actions 中重新扫描全部题目，仅补充当前没有显示对应内容的讲义区域。保留既有对应页、题面、题号、答案和学习记录；新增对应关系依旧由题目内容签名校验。

补查覆盖知识清单、速成班讲义、肖秀荣背诵手册、腿姐背诵手册和适用的史纲专题资料。证据均是原文件识别文字中的连续原文片段，按原有图片源显示截图。不把封面目录或故意设错的手册自测页当作理论讲解。

匹配保留主要/根本/首次等限定关系，清理混入考点句的“技巧助背”等提示语。短定义还须能核对明确主语、谓语和完整概念；一般词语相似、否定含义相反或不同学科的内容不能据此匹配。题干明确点出新思想世界观和方法论时，按该实际考点检索，避免目录章节归属误导。

定位文件请求失败与暂未确认对应内容分开显示。请求失败时可在讲义区域重新加载，不记入做题次数，也不改变答案。

详细补查结果、未确认项目和原始资料指纹见 `data/lecture-recheck-report.json`。未确认的内容继续保留提示，不为减少空白而填入相近章节。
