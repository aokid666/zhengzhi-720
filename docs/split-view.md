# v123：做题与整本讲义分屏

- 做题页侧边按钮开启、收起双栏，默认各占一半。左侧保留题目 DOM、选择、解析和笔记；右侧复用整本讲义浏览，滚动独立。下一题自动跟随本题匹配页，同一道题提交或切换外观时不重置右侧位置。
- 中间竖杠支持鼠标、触控、方向键和 Home；双击恢复对半。宽度保存在本机，并限制最小区域宽度。屏幕旋转与顶部工具栏高度变化后重新测量。
- 「我的 → 讲义分屏」设置按钮左/右侧及默认知识清单、速成班讲义、背诵手册；分屏内可临时切换来源、定位本题和关闭。缺少匹配页时明确提示，用户可选择从开头浏览。
- 背诵手册采用原 PNG，407 页上下册连续浏览，支持原书页码＋分册跳转、专题目录、全文查找和原有放大、批注。手册和其他题面共享原页批注键。
- 同源讲义浏览器以受限嵌入模式运行，隐藏重复导航，不加载题目和学习队列。批注共用 IndexedDB 和跨页面通知，云端自动同步由主页面承担；关闭/切换前等待批注落盘。内部导航使用完整 URL 与 replace，不向主页面的返回历史插入讲义路由。
- 未修改学习记录格式、原题库、匹配数据、截图与 userdata 分支。偏好是本机设置。

验证：58 项 Node 检查、原有 practice-ui.mjs 回归；split-ui.cjs 在真实 Chromium 验证三来源定位、独立滚动、触控/鼠标调宽、键盘操作、选项保留、夜间模式、手册上下册/搜索、无匹配提示、批注共享、偏好重开与手机双栏布局。浏览器测试只使用合成记录并拦截外部图片请求，不读取用户真实学习数据。
