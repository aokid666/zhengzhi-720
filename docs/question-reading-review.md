# 逐题阅读讲义复核

v138 改用可追溯的逐题复核清单。`scripts/semantic-reference-reviewed.json` 中每题有明确的考点判断、题意到原理的推理、所选原文和该原文能说明的正确选项。应用程序只验证并落地清单，不以相似度生成新的页码。

本轮精读清单覆盖腿姐八套卷 70 道题、138 个原页片段。多选题分别标注选项依据；只有全部正确选项都有相应原文时，才标为本资料完整覆盖。部分依据会明确注明未覆盖的选项，仍需继续补查，不能将相关概念页当成整题解析。

例子包括海葵测速的相对静止尺度、价格变化与资本价值构成、社会形态更替中的前进与曲折、为什么能自我革命的三项原因、道德最基本功能与其他功能的区别，以及抗战胜利意义的国内和国际两个维度。否定设问应当用原文纠正错误选项，不能把选中的错误表述当成正面事实。

综合卷 16 道题的模块与实际内容不符，本次仅更正这些题的 `module`，并同步迁移两种补充映射的内容签名。题号、题干、选项、答案、解析、图片地址和用户记录均保留。模块变动有逐项理由和原值检查，独立修改过的题目会使校验停止，避免覆盖。

所有原文逐字核验；额外资料还核对原 PDF 的 SHA256 身份。原图地址继续使用，未下载 PDF 重制或转换截图。验证和数据写入在 GitHub Actions 执行。完整复核结果见 `data/semantic-reading-review-report.json`。

这是一轮明确范围的复核，不表示全站其余未定位区域已经全部阅读完毕；部分选项依据也不能计作整题已完成。
