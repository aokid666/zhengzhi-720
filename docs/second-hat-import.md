# 二刷学成与肖帽子题

原始10份PDF保存在独立仓库 zz-second-hat-2027。文字、字体颜色、原文字符坐标提取及首代225dpi无损PNG截图生成均由GitHub Actions完成。截图只生成一次，不转换JPEG/WebP，前端按原页坐标展示。

二刷五模块采用原题干、对应内容与原书答案配对，支持连线与填序号、跨页与多对多。史纲26组与已收录内容相同；思修23组题目相同、顺序有所变化。两者复用旧题ID、数据和截图，保留已做记录、收藏和笔记，避免重复导入。

肖帽子题按原文条目生成蓝色答案挖空。结合真实连线题“题干—对应内容”、已有选择题的题干和正确选项，区分蓝色设问提示与蓝色答案，处理答案写在句首的倒装陈述。没有明确系词的条目保留逐条审核的语义锚点；不靠“冒号前不挖、冒号后全挖”判断。

同一词组不会因字体片段而拆成多个空；跨行的同一组遮挡同步揭晓。原图与原位文字模式共用坐标、遮挡组和揭晓状态。原位文字采用SVG原文坐标和原跨度宽度，深色模式使用可读颜色。自评掌握/仍需复习计入原有学习记录，直接切换模式与揭晓不增加次数。

首页及冲刺资料合集提供“二刷学成”和“肖帽子题”入口，按模块、章节选择，支持题号网格、错题收藏、笔记、分屏和云端同步。两类内容可分别进入艾宾浩斯复习。

构建只在题目配对、题干蓝字保护、原图引用和回归测试通过后发布。发布前合并最新main，不强推，不改动userdata分支，不重写已有题目记录。
