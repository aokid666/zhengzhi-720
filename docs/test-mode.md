# 测试模式

做题页可切换练习模式和测试模式。单选、多选、判断、连线为客观测试题；材料分析、揭晓后自评的挖空和既有重做区保持原流程。

测试期间，选择与配对只进入独立草稿。单题“保存本题”不批改、不展示答案解析，也不改变次数、错题、自动收藏或艾宾浩斯进度。返回任一题可修改，按最后一次选择结算；同一题只计一次。历史答题结果在本轮测试中隐藏。讲义分屏入口在测试时收起，提交后恢复。

“提交测试”以及离开题目路由都会统一批改已完成的客观题。选择题至少有一个有效选项，连线题必须每项完成且序号有效。未完成配对不计入分母，报告另行说明。统计按已完成题目计数，显示总数、对错数及百分比，不按连线条数增加题数。

结算窗口有关闭、从第一题开始复习两个按钮。复习按本次首次作答顺序，只遍历本次已完成题目，并展示本次提交的选择；再次查看报告和解析不会重复增加做题次数。可“再测一轮”。

草稿与最近一次报告暂存在标签页 sessionStorage，刷新同一题目界面可继续。尚未批改的草稿不混入已评分进度。结算结果使用原有记录和同步流程；每题附带本轮标识，重试恢复不重复计次。题库、讲义匹配数据和 userdata 分支不改动。
