# 全站苏一讲义配对 v148

覆盖全部23项练习题库及720题、专题练习、190题和手册点拨习题，共4662道独立题目。按正确选项、每个挖空、每条连线拆分核验；主观题和判断订正只展示已定位的原理，不自动宣称完整解答。

## 本轮结果

- 答案考点已定位：783题。
- 部分考点已定位：793题。
- 相关原理：367题。
- 待核实：2719题。待核实不代表讲义没有相应讲解，OCR和同义表述均可能造成漏检。

全库匹配在GitHub Actions运行；原文固定搭配和题干的限定关系均须满足核验条件。封面、目录、版权页、混排错误干扰项的表格不作为自动证据。长选项只匹配到一部分理论表述时，保留为相关原理，不晋升为完整覆盖。原文引文、全页文字SHA256、题目签名及每个作答单位的覆盖范围保存在 data/suyi-all-pairing-report.json。

人工精读与程序检索明确分开：v147的20题保留，本轮另人工核对22题/考点决定，见 scripts/suyi-additional-reviewed.json。文化自信的依据改取含“说到底”的表格续行，避免以只有四个自信的标题代替关系说明。材料的政策应用或复合连线只核对了部分理论时，仍保留相关原理状态。

## 展示与复核

题目讲义对照中的苏一标签显示覆盖数、未确认单位和原文截图。首页有全站配对进度入口，可按题库、状态和关键词筛选；50题分页，进入题目后返回保留筛选。网页仅下载精简的 data/suyi-pairing-status.json，完整审计按需取用。所有既有讲义对照、题库、学习记录保持不变。

复核：python scripts/package-suyi-audit.py --check。仅检查来源、签名、逐单位覆盖和已发布内容；不在校验时重新匹配。人工清单应逐项精读后添加，不能用提高匹配率代替语义核实。
